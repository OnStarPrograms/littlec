Data Graph Representation of Each Operations' Memory

Project 3 Submission by Aiden Thomas, Stepan Pechenkin, and Grecia Ocando

GitHub Link: https://github.com/OnStarPrograms/littlec

The graphs above show how many levels had to be travelled in order to reach their intended place in each respective tree during each operation. A large dataset (1000-10000 items) shows the overall efficiency of each tree type.

As you can (hopefully) see from the graphs above, the trees work in logarithmic time. The current implementation of the Trie tree seems to be more efficient in storing data overall, but has points in which it may spike in inefficiency. The Splay tree is less efficient, but is overall more consistent.
